# Modern Calculator

A modern, iOS-inspired calculator built with Next.js App Router, TypeScript, and Tailwind CSS.

## Features

- Standard operations: add, subtract, multiply, divide
- Decimal support, percentage, sign toggle, clear, and backspace
- Chained operations with correct precedence
- Keyboard support for digits, operators, Enter, Escape, and Backspace

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```

## Tests

```bash
npm run test
npm run test:e2e
```

## Deploy to Vercel

1. Go to https://vercel.com/new
2. Import `patneyland/vercel-calculator`
3. Framework preset: Next.js (auto-detected)
4. Click **Deploy**

No additional configuration is required.
